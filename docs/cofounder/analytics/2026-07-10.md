## Two real drop-offs worth fixing
1. **84 drafts created, 0 marked `sent`.** The `interactions` table has 84
   `drafted` rows and zero `sent`/`replied`. Either users draft outreach and
   never send (the core value — "a verified way in" — dies at the last step), or
   **we don't instrument "sent" at all**. This is the single most important thing
   to know and we currently can't tell which. → Instrument a `message_sent` event
   (and confirm the send path writes an `interactions` row). Until we can see
   sends, we're blind to whether the product actually works.
2. **24% of compose runs are interrupted.** `compose_runs`: 27 complete, **9
   errored — all "Interrupted — the run never finished."**, 1 needs-disambiguation.
   Runs are long (resume:tailor averages **133s**, source-HM 28s, research 16s),
   so people navigate away or time out mid-run. → Instrument `run_started` +
   `run_abandoned` to measure it precisely, and treat run latency as a UX risk.
